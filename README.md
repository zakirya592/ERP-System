# ERP System

React, JavaScript, and Tailwind CSS app built with Vite.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — lint the project
- `npm run preview` — preview the production build

Copy `.env.example` to `.env` and set `VITE_API_URL` when you connect a backend. The Axios client lives in `src/utils/userRequest.jsx`.
